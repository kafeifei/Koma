# 扩展管理

设置中的「插件」管理当前服务的 OpenCode 后端插件；「集成」管理当前项目的 MCP 连接。原生 Codex 任务不会自动获得 OpenCode 插件的工具或 hooks。终端 UI 插件与外部生态客户端不进入桌面扩展目录。

## 插件

支持 npm 包名（可带版本）或服务端的本地绝对路径。安装先下载、验证后端入口及声明的 OpenCode 版本范围，记录实际 npm 版本；此步骤不导入插件代码。实例初始化时复用上游插件加载器运行已启用插件。

安装记录、启用配置和每个已加载实例的运行结果分别保存或观察。更改开关、选项或卸载不会销毁正在使用插件的实例：界面显示「待重新加载」，原实例保持现状，后端重新启动后按最新记录加载。新初始化的项目也会读取最新记录。Koma 不自动重启后端。

卸载移除 Koma 的安装记录；保留共享 npm 缓存、本地源文件及插件自行创建的数据、操作系统计划任务等外部资源。当前实例仍持有插件时，该行保留并显示待重新加载。配置文件声明的插件显示为外部管理，不会被设置页覆盖。

插件和后端处于同一进程，继承其文件、网络和命令执行能力；Agent 的工具审批不是插件沙箱。第一批目录包含已做安装与加载验证的 Markdown Table Formatter，其他包可手动添加，是否兼容仍以实际加载结果为准。

## 集成

MCP 连接按服务端解析后的项目目录保存，可配置远程 URL 或本地执行程序、参数；高级选项支持上游 MCP 的环境变量、请求头、OAuth 和超时配置。保存后连接，关闭后断开，移除时关闭客户端并移除该项目记录。已有配置文件中的 MCP 项目只读显示。

项目存在运行中任务时，管理接口拒绝更改连接，返回可重试的冲突状态。空闲检查、连接变更与任务进入运行状态使用同一个项目锁，避免检查完成后恰好有新任务启动。网络连接失败仍保留配置，并显示实际错误，可通过重新启用或保存重试。OAuth 使用已有 MCP 授权流程；移除连接保留授权记录，避免撤销其他项目使用的同名授权。

## 存储与接口

管理记录位于当前 profile 的配置目录下 `koma-extensions.json`，版本为 1。读改写由跨进程锁保护，临时文件写入后原子替换，文件权限为 0600；损坏的记录不会被自动覆盖。现有 `opencode.json/jsonc` 不被修改。

- `/global/extensions/plugins`：查询、安装、修改插件。
- `/global/extensions/plugins/:id`：卸载插件。
- `/extensions/integrations?directory=...`：查询、保存当前项目连接。
- `/extensions/integrations/:name?directory=...`：移除当前项目连接。

接口使用现有服务认证和目录路由；界面使用所选服务的 URL 与凭据，不固定连接本机。运行状态仅代表响应请求的后端进程，同一 profile 下其他后端的已加载实例会在其下一次加载时采用持久记录。
