# 工作台的数据与目录边界

工作台复用 OpenCode 的 Project、Session、输入持久化和事件链路。持久任务以 Session 表示，顶层列表以 root Session 为主；一次调用、进程和未发送输入都不是独立任务。

## 项目与任务

- 项目按 server scope 和规范化目录身份归组，显示名称不承担身份；已有 worktree 属于原仓库，仍保留自己的执行目录。
- 项目选择器只列已打开项目，已有 worktree 从项目管理器打开；选择当前项目不跳回仓库根目录。
- 首页和侧栏共用所属 server 的索引与事件缓存，搜索由后端查询。未取得运行状态只表示加载中；分页、重连和旧请求不覆盖新事件。
- 标题、归档和运行状态由后端持有；置顶、展开等界面偏好按本地 scope 保存，不代表后端状态或跨端同步。

入口：[共享索引](../packages/app/src/context/global-sync/home-session-index.ts)、[任务侧栏](../packages/app/src/pages/layout/task-sidebar.tsx)。

## 未发送输入

- 每个窗口的新建输入框复用一份临时草稿，内部 `DraftTab` 只是路由与目标元数据适配；server 和实际目录不再决定草稿身份，正式会话沿用自己的输入 key。
- 切换、关闭、刷新保留文字、附件、上下文和权限选择；首次发送只清除已提交版本，保留权限选择，不覆盖等待期间的新输入。
- 切换项目或 server 只更新发送目标，保留同一个页面、输入框及其文字、附件和上下文；创建 worktree 不改变草稿身份。提交捕获当时的目标，等待期间的切换不改写已提交任务的归属。
- 普通打开不覆盖输入；非空预填等待持久化加载完成，再以空行追加，保留原附件位置和上下文。
- 模型、推理和权限偏好按 server、项目及引擎分别保存；当前输入的显式设置优先，模型目录未加载不覆盖保存值。正式会话以所属后端状态为准。
- 旧 UUID 草稿在 tabs 加载后清理一次，保存文档删除成功才移除索引；失败索引保持隐藏，下次加载接续。旧目录输入保留以兼容已有 URL，新建入口统一使用窗口输入框草稿；无孤立文档扫描或跨窗口实时合并。

入口：[输入身份与迁移](../packages/app/src/context/input-retention.ts)、[提交](../packages/app/src/components/prompt-input/submit.ts)。

## 分支与隔离目录

- 来源目录、分支和新建 worktree 开关各自独立；开关不导航、不搬输入，控件选择不提前修改 Git。
- 分支按 server 和项目恢复手动选择；无记录时依次选 `main`、`dev`、当前分支。保存分支暂不可见时不静默替换，隔离偏好独立保留。
- 首次发送统一捕获目录、分支和隔离选择：开启则从所选分支创建目录；关闭则由后端完成本地分支 checkout，再创建 Session。OpenCode 与 Codex 共用准备步骤。
- 选项未就绪、冲突或占用时保留输入与选择；非 Git、无提交目录不执行 checkout。已有任务的目录不由新建控件改写。
- 目录浏览通过鉴权的一层列举 API，不初始化项目运行时、递归索引或文件监听；缺少接口时不回退到项目文件接口。

入口：[选择控制器](../packages/app/src/pages/new-session/new-session-workspace-controller.ts)、[目录列举](../packages/server/src/handlers/directory.ts)。

## 归档、恢复与删除

- 操作由所属后端执行，UI 按 capabilities 开放；未接入宿主生命周期的 V2 服务不具备这些操作。
- 归档保留历史和输入，拒绝新消息、命令与 shell 执行；已开始的执行不中断，运行状态与停止入口保留。
- OpenCode 后台子任务的内部完成结果向父 Session 幂等持久接收，保留用户所选模型、档位和权限；已归档父任务接收结果但不启动新执行。
- 受管目录仍驻留且 Git 身份匹配时，恢复撤销未完成归档并保留终端、占用和文件；同一 checkout 的分支改名不阻断恢复。
- 目录已回收时，完成重建、文件还原和恢复收尾后才解除归档。原分支已删除时，从校验过的快照恢复原提交，不改用当前分支或覆盖同名分支；非受管目录不由恢复创建。
- 删除检查执行占用、目录身份与保存状态；归档或恢复失败仍可重试删除，无法确认时保留数据。恢复失败且 checkout 已缺失时，保留同名分支和其他 checkout。
- 归档重试可在确认同一 checkout 后沿用实际分支，但必须重验快照；分支变化后不再拥有该分支的删除权。
- V1、V2、Codex 与 PTY 接入同一后端的目录占用边界，覆盖路径别名及包含关系；不提供外部进程、终端后续 `cd` 或脱离后端子进程的全系统检测。

入口：[生命周期](../packages/opencode/src/worktree/lifecycle.ts)；Codex 原生历史、删除回执与子任务边界见 [Codex 模块](../packages/codex/README.md)。

## 文件快照与管理

- 回收保存暂存、未暂存、普通未跟踪及 ignored 本地文件，包括 `.env`、数据库和证书；仅跳过明确可重建依赖／缓存。
- 符号链接只保存链接；特殊文件、嵌套仓库或读取失败阻止回收。删除目录前重验快照，恢复不覆盖同路径文件，兼容已有快照格式。
- 管理视图来自 Git 清单和生命周期记录。主 checkout 以 Git 为准；显式接管不创建 Session 或改分支，也不取得既有用户分支的删除权。主目录、共享及外部目录不自动接管或回收。

入口：[文件快照](../packages/opencode/src/worktree/archive.ts)、[管理](../packages/opencode/src/worktree/manager.ts)。

## 成果合回

- 合回独立于归档，使用临时 index 与三方合并预览，包含已提交、未提交和普通未跟踪结果，不包含 ignored 文件。
- 应用前校验双方 HEAD、来源 tree、合并 tree 和冲突选择对应的 `reviewID`；双方无后端占用，目标干净且无进行中的 Git 操作。
- 冲突逐文件选整份版本并重新预览；不默认选边。复杂目录／重命名冲突、过期预览、文件碰撞或读取失败拒绝应用并保留文件。
- 结果只进入 Git 主 checkout 的暂存区，不隐式提交、移动分支或随归档合并。

入口：[合回服务](../packages/opencode/src/worktree/merge.ts)。
