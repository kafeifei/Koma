# Contributing to Koma

Start product changes from `main` and open pull requests against `main`. `dev` only mirrors upstream OpenCode; do not submit Koma changes there.

See [branch and synchronization policy](docs/branches.md), [architecture](PROJECT.md), and [desktop releases](docs/release.md).

For upstream engine contributions, see the [OpenCode contribution guide](https://github.com/anomalyco/opencode/blob/dev/CONTRIBUTING.md).
