# Generated Codex app-server protocol

The TypeScript files in this directory are generated by `codex app-server
generate-ts --experimental` from `codex-cli 0.154.0`. They are Apache-2.0
licensed upstream output and must not be edited by hand.

Run `bun run generate:protocol` from `packages/codex` to regenerate them with a
matching local binary. `bun run check:protocol` verifies the committed tree
without changing it.
